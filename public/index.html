College DSA-II Viva Questions & Algorithmic Defense
Examination Ready

Q1: Why use an AVL Tree for course catalog indexing over standard BST or Hash Table?

Answer: An ordinary BST can degenerate into a linked list with O(N) worst-case time for sorted insertions (e.g. course codes inserted chronologically). An AVL Tree strictly enforces a balance factor ∈ {-1, 0, +1} through 4 rotation cases (LL, RR, LR, RL), guaranteeing strict O(log N) worst-case search, insertion, and deletion. Unlike a Hash Table, the AVL Tree maintains elements in sorted order, enabling efficient in-order traversal and range queries [CS200, CS400] without sorting overhead.

Q2: Why compare BFS and Dijkstra for learning paths?

Answer: BFS operates on unweighted graphs and computes the shortest path in terms of the minimum number of edge hops (i.e. fewest prerequisite course stages, O(V + E)). However, a course hop may have varying academic difficulty or workload. Dijkstra's algorithm uses a Min-Priority Queue to minimize the cumulative cognitive effort weight (O((V + E) log V)), providing students with the most manageable learning curve even if it contains more intermediate foundational steps.

Q3: How does the Max-Heap prioritize course recommendations?

Answer: The Max-Heap stores candidate courses keyed by a multi-criteria heuristic score combining track interest alignment (up to 40 pts), student GPA rigor fit (up to 25 pts), prerequisite readiness (15 pts bonus for fully unlocked courses), and credit budget compatibility. The top-K courses can be extracted in O(K log N) time, which is significantly faster than sorting all N courses (O(N log N)) when K << N.

Q4: Explain the 0/1 Knapsack formulation for elective optimization.

Answer: Each elective course has an integral weight (credits) and a value (composite academic benefit score). The student credit budget acts as the knapsack capacity W. Since each course can only be enrolled once (0 or 1), the problem satisfies optimal substructure: dp[i][w] = max(dp[i-1][w], dp[i-1][w - wt[i]] + val[i]). The optimal set is reconstructed via backtracking from dp[N][W] in O(N × W) time.

Q5: What is the difference between Kruskal's and Prim's MST algorithms?

Answer: Kruskal's algorithm is edge-based: it sorts all edges and uses Disjoint Set Union (DSU) with path compression and union-by-rank to greedily add edges without forming cycles (O(E log E)). Prim's algorithm is vertex-based: it starts at an arbitrary vertex and greedily grows a connected component using a Min-Priority Queue (O((V + E) log V)). Both yield identical minimum total weight, as demonstrated in our test suite.
